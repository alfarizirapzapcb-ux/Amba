Nexus Touch

Tombol layar virtual saat bermain. Aktifkan lewat Aksesibilitas.

Ukuran tombolOpasitas tombol
Cara pakai
1. Aktifkan Nexus Touch.
2. Pilih game, ketuk Mulai Game.
3. Overlay muncul otomatis saat game terbuka. ＋ = tombol ketuk, A = pad bidik (geser).
4. Seret tombol ke posisi, seret titik merah ke tempat yang mau diketuk/dibidik.
5. Mode edit: ketuk tombol = turbo ⚡, tahan lama = hapus. ▶ main, ✎ edit.
6. ⚙ di overlay: Nexus Genie (sensitivitas, crosshair, kecerahan, volume, salin/tempel konfigurasi). Tersimpan per game.
